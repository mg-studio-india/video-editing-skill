# Duration and delivery

These ranges help estimate export and review needs. They do not prescribe narrative beats or require a specific visual-change interval.

| Delivery length | Common use | Planning considerations |
|---|---|---|
| 3–15 seconds | Short social clip, bumper, visual loop | Preserve enough source context to understand the moment; loop only when the material supports it. |
| 15–60 seconds | Short social edit | Keep the source's essential setup and payoff; don't force a hook or outro. |
| 60 seconds–3 minutes | Demonstration, interview, explainer | Follow actual topic or action changes; add graphics only where they clarify source material. |
| 3–20+ minutes | Talk, documentary, lesson | Use chapters where the source changes subject; preserve reasoning and useful pauses. |
| Recurring series | Episodic content | Reuse a signature only when the user or brand guide asks for it. |

Ask which platform and canvas the export should target. Preserve the source aspect ratio when the user has not chosen another format; inspect reframing rather than applying a blind center crop. Follow platform safe zones for the selected canvas.
